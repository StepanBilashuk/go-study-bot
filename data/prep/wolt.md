🎯 Wolt — interview prep

Process: take-home assignment → system-design & discussion round (~90 min, two senior/staff engineers). Focus on production-quality code and architecture, not algorithm puzzles.

▸ Take-home (production-grade code, ~2 weeks, your language)
They test your code against their own suites and look for: clean package structure, middleware, logging, resilience/error handling, and TESTS. Example: implement an API.
Study: /learn api-design · /learn idempotency · /learn caching
Treat it like production: structure, observability (/learn observability), graceful failure.

▸ System design round
Discuss your take-home, then an open-ended design + pointed questions (e.g. "what variables/types would you define to implement feature X").
Study: /design framework · /design food-delivery (Wolt's domain)
Building blocks: /learn partitioning · /learn caching · /learn trees · /learn arrays-hashing (their required set)

▸ Behavioral / values
Ownership and end-to-end thinking; how you reasoned about trade-offs in the take-home.
Prep: /story (ownership, tradeoff) · /boss behavioral
