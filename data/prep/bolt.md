🎯 Bolt — interview prep

Process: recruiter → live coding → system design (whiteboard/Excalidraw) → behavioral (HM). Algo-heavy; avg ~40 days for senior. Below are REAL questions reported by recent Bolt candidates, mapped to what to study.

▸ Coding (LeetCode medium/hard, live editor)
Reported: Serialize/Deserialize an N-ary tree · Lowest common ancestor in a family tree · Enumerate anagrams / "blanagrams" · Minesweeper: count adjacent mines.
Study: /learn trees · /learn arrays-hashing · /learn backtracking · /learn graphs · /learn math-geometry
Grind NeetCode mediums; talk through your approach out loud.

▸ System design & technical discussion (reported themes)
Design a distributed message queue with strict ordering within a partition → /design + /learn message-queues · /learn kafka-log-based
Design a proximity service (search millions of geo-coords) → /design proximity-service
Design a video transcoding pipeline → /design video-streaming
Architect a distributed cache → /design distributed-cache
Graph partitioning & data locality → /learn partitioning · /learn advanced-graphs
SQL vs NoSQL trade-offs; DB indexes (read vs write); eventual vs strong consistency → /learn storage-retrieval · /learn transactions · /learn consistency-consensus
Design an API / a job scheduling service → /design framework · /design job-scheduler · /learn api-design
OOD: Parking Lot, Minesweeper architecture → /learn object-oriented-design · /design parking-lot
Bolt domain (mobility): /design ride-sharing · /design food-delivery

▸ Behavioral (ownership, communication, growth)
Reported: being proven wrong (and learning) · taking a professional risk · struggling to meet a deadline · a difficult coworker · mentorship · balancing tech debt vs a new feature · why Bolt / expected tenure.
They value: communicate clearly, own mistakes, ask for help — perfection isn't expected.
Prep: /story (failure, conflict, tradeoff, ownership, mentoring) · /stories · /boss behavioral

Sources: Prepfully & InterviewPal candidate reports, Exponent, Glassdoor, Taro.
